## 2. Giới Thiệu Dự Án
Dự án cải tiến giao diện **Thẻ sản phẩm (Product Card)** dựa trên khảo sát thực tế sàn thương mại điện tử **Shopee** (https://shopee.vn).

## 3. Các Chức Năng Cải Tiến
- Bố cục dạng lưới (Grid layout) hiển thị 4 sản phẩm mẫu.
- Nổi bật nhãn phần trăm giảm giá (Badge) màu đỏ viền ở góc ảnh.
- Hiển thị giá bán khuyến mãi màu đỏ cam nổi bật, giá gốc gạch ngang mờ.
- Tích hợp sẵn nút "Thêm vào giỏ hàng" và hiệu ứng nổi (hover) khi rê chuột.
- **Responsive Web Design:**
  - Màn hình máy tính (Desktop): Lưới 4 cột (`repeat(4, 1fr)`).
  - Màn hình điện thoại (Mobile): Lưới 2 cột (`repeat(2, 1fr)`).

## 4. Công Nghệ Sử Dụng
- **HTML5:** Cấu trúc Semantic (`<article>`, `<section>`, `<header>`, `<main>`).
- **CSS3:** Flexbox, CSS Grid, Media Queries (`@media (max-width: 768px)`).
